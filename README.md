# Каталог идей

Сайт-справочник самодельных проектов: что можно смастерить и зачем это нужно.
Каждая идея описана человеческим языком, разложена по разделам и оценена по сложности
повторения — от «собрать за вечер» до «почти нереально в одиночку».

## Как устроено

- `index.html`, `assets/` — сам сайт, статика без сборки и зависимостей
- `data/ideas.json` — каталог: название, описание, раздел, сложность, ссылка на источник
- `tools/build.py` — сборка каталога из личной выгрузки
- `tools/check.py` — проверка целостности каталога перед публикацией

## Команды

    make build    # собрать data/ideas.json
    make check    # проверить каталог
    make serve    # поднять локально на http://localhost:8777
    make deploy   # опубликовать на GitHub Pages

Путь к исходной выгрузке задаётся переменной `SRC`.
